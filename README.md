# Schooltopia

一款可自定义学校事件、校园皮肤与规则权重的 12 周校园生存模拟游戏，结合匿名玩家研究与逐轮分析报告。

## GitHub 部署

- GitHub Pages 发布游戏和学校创建器界面。
- 研究后台 `admin.html` 不进入 Pages 公开站点。
- 本机的匿名试玩数据、学校编辑凭证、依赖缓存和旧压缩包不会上传。
- 创建学校、集中收集数据和逐轮研究报告需要运行 `server.js`，GitHub Pages 本身只提供静态网页。

这是《世外桃源》的独立复制与扩展版本。原版文件位于上一级目录，本项目不会读取或覆盖原版存档。

## 打开方式

需要 Node.js 18 或更高版本。macOS 可双击 `启动Schooltopia.command`，其他系统在本目录运行 `node server.js`。

- 游戏：`http://127.0.0.1:4180`
- 学校创建器：`http://127.0.0.1:4180/creator.html`
- 研究后台（仅管理者本机）：`http://127.0.0.1:4180/admin.html`

## 已实现

- 公开用户可以创建自己的学校版本，在 6 套主题之间切换并微调颜色、事件和变量权重，再得到专属游戏链接。
- 学校版本可一键重置：保留编辑权限，名称恢复为“未命名学校”，同时恢复默认皮肤与权重并清空自定义事件。
- 输入真实校园事件，自动生成三个剧情选择节点和属性变化。
- 游戏内含《Gymnopédie No.1》轻柔背景音乐，以及下课铃、翻纸、键盘和远处操场环境音，音乐与音效可分别关闭。
- 3D 学校创建器也有独立的音乐与编辑反馈音，并与游戏共享声音偏好。
- 匿名记录玩家路线、身份、年级段、玩家类型、选择、属性变化、结局与主动反馈。
- 统计试玩人数、人均游玩局数、平均轮数、常选选项、结局分布和群体差异。
- 自动生成压力路径、坏结局机制、校园体验诉求和学生生存策略总结。
- 分析玩家最常牺牲的属性、智慧追求倾向、藤校提示后的心情取舍、身份策略差异，以及最优选择与真实校园生活的相似度。
- 生成 Player Research Report，并可导出 CSV。
- 每完成一局固定生成并保存一份轮次报告；通关反馈会补充到对应轮次，不会另算新一轮。
- 每累计 5 局进行一次受限自动迭代：单次权重最多调整 0.05，范围限制在 0.6 至 1.4，并保留迭代记录。

## 数据位置

- 学校配置：`data/schools.json`
- 匿名研究数据：`data/research.json`

当前版本不收集姓名、账号、联系方式或精确位置。若要让不同设备共同提交数据，需要把整个 Node 服务部署到支持持久化磁盘的服务器，不能只上传静态 HTML。

分享源码压缩包默认不包含 `data` 中的试玩数据和学校编辑凭证；第一次启动时会自动创建干净数据文件。
